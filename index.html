8. REA dùng được gì

ViệcTrạng thái
inspect_android_package/class/method❌ cần file .apk standalone — thư mục giải nén không nhận
inspect_native_exports / open_binary trên .so✅ chạy tốt (đã dùng cho libsigner.so)
Đọc manifest + sources/ Javađọc trực tiếp (đã decompile sẵn)

Muốn dùng trọn bộ tool Android của REA → cần APK gốc (một file). pull_adb_package kéo từ thiết bị đã cài cho file hợp lệ.

9. Khoảng trống cần đào tiếp

  • Lớp network trong sources — host/endpoint, để biết AI chạy local hay cloud (§4).
  • Cách libsigner ký request (cần pseudocode native).
  • Remote Config keys — chiến lược bật/tắt tính năng & quảng cáo.
  • So sánh version nếu có APK khác (REA compare).
