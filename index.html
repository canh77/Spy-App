Chữ ký request

QUAN SÁTgenerateSignature(bundleId, appName) → fetchServerTimestamp() (GET timestamp) → buildSignature(timestamp): nạp public_key PEM → Cipher("RSA/ECB/PKCS1Padding") mã hoá → Base64 NO_WRAP. Trả (signature, timestamp, apiKey) gắn vào header.

5. Chống giả mạo / ký request

QUAN SÁTREA: libsigner.so — ELF arm64, 1.37MB, SHA-256 55353b75…. Truy tiếp trong Java: lib này thuộc Adjust SDK (com.adjust.sdk.sig.Signer + NativeLibHelper) — ký attribution chống gian lận, không phải chữ ký API generation.

QUAN SÁTChữ ký API generation nằm ở ApiSignatureUtil — Java thuần, không JNI: Cipher("RSA/ECB/PKCS1Padding") + public_key (từ Remote Config), kết quả Base64 NO_WRAP.

SUY LUẬNHai cơ chế ký tách biệt; chống tamper native có thêm libpglarmor.so (Pangle). Đính chính: nhận định trước ("API ký bằng libsigner") là sai — bằng chứng Java cho thấy khác.
