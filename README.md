# vidix-aivideo-teardown

Nghiên cứu cạnh tranh (competitive teardown) đối với app Android
`com.vidix.aivideogenerator.aiphotogenerator` — phân tích tĩnh phục vụ mục đích
nội bộ.

**Repo này chỉ chứa phân tích gốc của chúng tôi** (`ANALYSIS.md`): nhận định về
kiến trúc, SDK, quyền và hướng tiếp cận kỹ thuật, suy ra từ quan sát.

Repo **không** chứa, và sẽ không chứa, mã nguồn đã dịch ngược, tài nguyên,
model hay bất kỳ phần nào thuộc bản quyền của ứng dụng gốc.
